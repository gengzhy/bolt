LocalFastTransfer Windows 端 UI 设计规范（轻量拟物风 #4）
适配 Tauri + Vue3，可直接交给前端开发，包含：全局风格、三栏布局、组件规范、全部页面、弹窗、状态栏；参考你提供的效果图，修正图中文字错乱问题，完整还原「支持文件 + 文件夹拖拽选择」交互。

二、分模块详细 UI 规范
📍模块 1：左侧面板【可用设备】宽度固定 280px
卡片容器：圆角 18px，白色背景，一级阴影
头部：标题「可用设备」16px 半粗；右上角两个图标：刷新🔄、更多菜单 ⋯
设备列表项（每个设备卡片）
圆角 12px，白色，二级阴影，hover 上浮效果
内部：设备图标（PC / Android /iPhone）+ 设备名称 + 单选圆圈
状态标识：
在线：无标记
离线：文字置灰，图标变淡，不可选中
底部附加组件
【手动输入 IP 连接】折叠按钮；点击弹出输入框，用于 mDNS 发现失败场景
底部小字：本机IP: 192.168.x.x
交互：选中设备后，中间区域才允许选择文件 / 文件夹发送。
📍模块 2：中间核心操作区（支持文件 + 文件夹，效果图核心）
容器：圆角 18px，白色卡片，一级阴影。
状态 A：空闲状态（未拖拽）
中间大区域为拖拽接收区，背景色#F8FAFC，虚线边框#CBD5E1。
提示文字：
将文件或文件夹拖拽到此区域
支持单个文件、多文件、整个文件夹批量传输
主按钮：选择文件或文件夹（立体主按钮，点击打开系统文件选择器，可多选文件 + 可选择文件夹）
辅助按钮：发送文件夹 次级按钮。
状态 B：拖拽悬浮状态（鼠标拖入）
背景切换为浅蓝 #EFF6FF，显示半透蓝色玻璃浮层（就是效果图中间弹窗）
浮层文字不变，按钮高亮。
✨关键：Windows webview (Tauri) 需要开启拖拽文件夹能力，前端必须允许webkitdirectory属性。
状态 C：已选中资源
拖拽 / 选择完成后，中间展示已选清单：图标区分「文件 / 文件夹」，显示大小、数量；提供移除按钮。
底部出现【发送】立体蓝色大按钮。
📍模块 3：右侧面板【传输任务】固定宽度 300px
卡片容器：圆角 18px，白色，一级阴影
标题：传输任务，右上角更多菜单
任务列表，每一条任务项：

📍模块 4：设置页面（独立弹窗，不占三栏）

接收文件夹覆盖策略：询问 / 自动重命名
设备发现
mDNS 自动发现开关；自定义广播端口输入框
关于：版本号 LocalFastTransfer

全部弹窗：圆角 20px，悬浮大阴影，半透明遮罩层 rgba(0,0,0,0.2)
发送确认弹窗

待发送：3 个文件，2 个文件夹，总大小 2.3GB

从左到右排布：

三、交互逻辑要点（UI 必须绑定业务）
设备未选中时，中间的选择文件按钮置灰不可点击
文件选择器必须同时支持：多选文件 + 选择文件夹（Tauri api 调用系统对话框，前端模拟无法完整选文件夹）
拖拽：拖入文件、拖入文件夹全部识别；多个混合也支持
任务进度：实时从 Rust 后端 FFI 回调拿到速度、百分比，驱动 UI 进度条
断线：任务列表状态变为「断开」，提供重传按钮
拟物交互：所有卡片、按钮 hover 有微小上浮位移 transform: translateY(-2px)，按下往下 translateY(1px)
