# Bolt 隐私政策

**最近更新日期**：2026年9月18日  
**生效日期**：2026年9月18日  

欢迎使用 **Bolt**（以下简称“本应用”或“我们”）。Bolt 是一款纯局域网、点对点（P2P）、开源无服务器的文件传输工具。我们深知个人隐私与数据安全对您的重要性，并始终践行**“数据属于用户、本地传输无痕、绝不上传云端”**的隐私设计原则。

请在使用本应用前认真阅读本《隐私政策》，了解我们如何处理相关设备信息及保障您的数据安全。

---

## 1. 核心隐私承诺

* **零服务器与零云端**：我们没有中央服务器，不设用户注册系统，不收集、不上报、不存储您的任何个人隐私文件。
* **纯局域网直连传输**：所有文件收发均在您授权的局域网（Wi-Fi 或有线网）内两台设备之间直接点对点传输，不经过任何外部互联网节点。
* **零第三方追踪**：本应用不包含任何商业广告 SDK、行为统计分析 SDK 或第三方数据搜集插件。
* **端到端加密**：传输链路全程强制采用 TLS 1.3 高强度加密与 BLAKE3 校验，确保传输内容无法被局域网第三方窃听或篡改。

---

## 2. 我们如何处理设备信息与数据

由于 Bolt 属于点对点去中心化架构，应用仅在满足局域网互联互通所必须的范围内，在**您的本地设备**及**局域网对端设备**之间交互以下信息：

### 2.1 局域网发现与配对信息
* **设备名称与平台标识**：如您自定义的设备昵称、计算机名或系统类型（Windows / Android）。该信息仅通过 mDNS / NSD 在同一局域网广播，以便您和对方识别设备。
* **局域网 IP 地址与通信端口**：用于建立局域网 P2P 网络通道，仅在内网寻址使用。
* **加密证书指纹**：由设备本地随机生成的 Ed25519 自签名公钥指纹，用于 TLS 1.3 身份认证与 4 位配对验证码生成，绝不包含您的个人生物识别或硬件私密信息。

### 2.2 传输内容数据
* **文件元数据与数据流**：当您主动选择文件/文件夹发送时，文件名、大小、哈希及文件流仅向您指定的对端设备发送。
* **临时文件存储**：为保证传输完整性，接收端在传输过程中会暂存为 `.bttmp` 临时文件，校验成功后自动更名为原始文件。除您指定的保存路径外，本应用不会在任何隐藏目录冗余备份您的文件。

### 2.3 本地配置数据
* 您的设备昵称、下载目录、信任设备列表（TOFU 配对记录）均仅保存在您本地设备的应用私有存储空间中，随应用卸载彻底销毁。

## 3. 操作系统权限申请与使用说明

为了向您提供文件选择、发送、接收与局域网发现功能，本应用会在必要场景下向系统申请相关权限。我们郑重承诺：**绝不在非业务场景下申请或滥用权限**。

### 3.1 Android 端权限说明
| 权限名称 | 对应系统权限 | 调取目的与使用场景 | 授权类型 | 拒绝授权的影响 |
|---|---|---|---|---|
| **存储 / 访问文件权限** | `MANAGE_EXTERNAL_STORAGE` 或系统文件选择器（SAF）/ 媒体读取权限 | 用于您主动选取本地文件发送，以及将对方发送的文件保存至您指定的下载目录 | 必须 | 无法选取文件发送或无法写入保存接收到的文件 |
| **网络与局域网通信** | `INTERNET`、`ACCESS_NETWORK_STATE`、`ACCESS_WIFI_STATE` | 用于建立设备之间的局域网 TCP/QUIC 传输通道 | 必须 | 无法进行局域网通信与传输 |
| **局域网多播服务** | `CHANGE_WIFI_MULTICAST_STATE` | 用于 mDNS / NSD 协议在内网广播与自动发现同局域网下的其他设备 | 推荐 | 无法自动搜索发现设备，需退化为手动输入内网 IP 连接 |
| **通知栏提醒** | `POST_NOTIFICATIONS` | 用于在后台传输大文件时，在系统通知栏实时显示传输进度、速度及传输完成/失败提示 | 可选 | 不影响传输功能，但无法在锁屏或后台直观查看传输进度 |

### 3.2 Windows 端权限说明
* **本地网络回环与防火墙通信**：首次运行时若弹出 Windows Defender 防火墙提示，请允许本应用在专用网络（局域网）通信，以便监听传输端口与完成 mDNS 服务广播。
* **本地文件系统访问**：用于读取您拖拽或选取的文件，以及将接收文件保存到您设置的目录中。

## 4. 数据安全保障机制

我们通过严格的工业级技术架构保障传输过程的安全：
1. **传输加密（TLS 1.3）**：通信链路全程强制 TLS 1.3 加密，不支持任何明文降级模式，防范局域网中间人监听与嗅探。
2. **设备认证（TOFU 机制）**：首次配对采用 4 位动态验证码与公钥指纹核验；信任对端后保存其公钥指纹，若对端证书异常变更将即刻报警阻断。
3. **数据完整性（BLAKE3）**：文件收发全链路进行 BLAKE3 哈希校验，确保文件在传输链路中未出现任何字节丢失或篡改。
4. **零外网暴露**：应用无任何外网反向代理或公网穿透功能，只要您的局域网环境安全，外部互联网节点无法触达本应用通信端口。

## 5. 第三方 SDK 与服务说明

* **无第三方追踪 SDK**：Bolt 未集成任何第三方的商业广告、统计追踪、用户画像或行为分析 SDK（如无 Google Analytics、友盟、Bugly、极光推送等）。
* **操作系统及设备厂商机制**：请您理解，本应用基于底层操作系统（Windows / Android）运行。操作系统本身（如厂商自带的剪贴板管理、系统级备份机制）对您设备数据的处理适用该系统厂商的隐私政策，超出本应用的控制范围。

## 6. 您对个人数据的权利与控制方式

基于本应用的去中心化架构，您对所有数据享有完全的自主控制权：
1. **删除配对与信任设备**：您可随时在应用“设置”或“已信任设备”中清除特定或全部设备记录，清除后需重新扫码/核验验证码方可连接。
2. **更改保存目录与设备昵称**：您可随时修改对外展示的设备名称，或更换文件接收存储路径。
3. **彻底清除数据**：由于所有配置均保留在本地，您在系统设置中选择“清除数据”或直接“卸载应用”，即可永久彻底删除本应用在您设备上的所有配置与记录。
